# Reporting Policy

## Cadence
- Weekly cadence, sent every Monday at 09:00 UTC.
- Reporting window covers the previous week: Monday 00:00:00 UTC through Sunday 23:59:59 UTC.
- All calculations and grouping use UTC to avoid cross-timezone drift.

## Thresholds
- Target hours per person per week: 40 hours.
- Warning threshold: > 40 hours/week.
- Over-limit threshold: > 45 hours/week.
- Role/profile overrides are allowed when defined (e.g., part-time profiles can set lower targets).

## Recipients
- Project-level reports: assigned project leads for each project.
- Organization-level summary: delivery leadership and finance stakeholders.
- Default stakeholder list: delivery-leads@company.com, finance@company.com.

## Notes
- When a profile-specific threshold is present, it takes precedence over the global threshold.
- If no profile override exists, the global thresholds apply.
